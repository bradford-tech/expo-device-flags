# @bradford-tech/device-flags-server

Server-side companion for
[`@bradford-tech/expo-device-flags`](../expo-device-flags): ES256 JWT signing
with your DeviceCheck key and typed `query_two_bits` / `update_two_bits` calls
against Apple's DeviceCheck server API.

**Status: in development.** Nothing is published yet; this package exists so
the monorepo wiring is real. The client half is published and usable today.
